How to install

Bh is a Rails engine. It brings Bootstrap 6 with it, so nothing else goes in the Gemfile.

# Gemfile
gem 'bh', '~> 6.2.0'

~> 6.2.0 stops short of 6.3, and that is the pin to hold: until this line settles it breaks on a minor, not on a major. Rails 8.1 and Ruby 3.2 are the minimum.

6.2.0 breaks everything before it and keeps its major anyway. 6.0 through 6.1.4 were an alpha in everything but the number — Bootstrap 3 wrappers with a Bootstrap 6 stopgap bolted on, cut while Bootstrap 6 was itself pre-release — so there was no settled API to break. Those numbers are taken and cannot be withdrawn, RubyGems keeping anything published over thirty days ago, so this release steps over them.

In the head

With the gem in the bundle an app serves /bh/css/bh.css and /bh/js/bh.js itself. One helper puts both in the head, along with everything Bootstrap and Turbo read.

<%= bh_head_tags %>

Bh links no icon font of its own: which glyphs a page draws is the host's business, and a gem reaching for somebody else's CDN unasked is not. A combobox's chevron and a bookmark's star are Bootstrap Icons, so a page that wants them says where they come from.

The form

Given to one form as builder:, or to every form of a controller through default_form_builder. What a view passes is kept: its classes join the builder's, its data is merged key by key with the builder's, and any other option of its overrides.

class ApplicationController < ActionController::Base
  default_form_builder Bh::FormBuilder
end
<%= form.fieldset 'Your code' do %>
  <%= form.label :pin, '6-digit code' %>
  <%= form.pin_field :pin %>
  <%= form.submit 'Confirm' %>
  <%= form.button 'Call us', type: :button %>
<% end %>

Combobox

A <select> drawn as a searchable menu, which stays the one thing the form submits. Its :prompt is what the toggle says before anything is picked; every other argument is the select's, and multiple: gives each row a check.

<%= form.combobox :county, counties,
      { prompt: 'Pick a county' },
      multiple: true %>

The same thing by hand is a select carrying data-controller='combobox' and nothing else in the markup.

The 6-digit code

One real field rendered by Bootstrap as six slots: digits only, exactly six, and autocomplete='one-time-code' so a phone offers the code from the text that brought it. A pasted or autofilled code is a whole one and sends itself; a typed one waits, since the sixth digit may be a typo.

<%= form.pin_field :pin_confirmation,
      required: true %>

Phone numbers

A North American number reads 555-555-5555, decided in the browser and nowhere in Ruby. The server hands over ten digits; the controller formats a cell's text and a field's value on connect, keeps the separators as it is typed, and gives the field pattern, placeholder, title and inputmode where the markup left them blank.

<%= form.phone_field :phone %>

Dialogs

A link and the dialog it opens: headed, with an X, holding the block, and closed by an Okay too — okay: words it otherwise, okay: false leaves it out. The two share an id made from the link's own words, so a page invents none. The browser's own element brings the backdrop, the focus trap and Esc; nothing is scripted.

<%= dialog 'I’m not on Google Business',
      title: 'Not a problem' do %>
  We will look your business up ourselves.
<% end %>

Toasts

What the flash says, as a fixed stack at the bottom right: green for a notice, red for an alert, the primary for any other key. Visible at first paint so a message stands before any script runs, and data-turbo-temporary so it never replays from a Back.

<%= notices %>

The hide is two seconds, held while a reader hovers or focuses a toast, with an X for whoever will not wait. Only words are shown: a value in the flash that is not a string is another part of the host's data and is passed over.

Chat

A thread of messages, newest at the foot, and — where url is given — the field that posts the next one there, suggesting hints one at a time. Any object answering side, text, sender, at, delivery and cost is a message; Bh::Message is for a host that has the facts and no model to hang them on.

<%= chat_with url: questions_path,
      hints: Chat::HINTS,
      messages: messages %>

Flow

The page of a signup flow: header over the title and line the view set in content_for, one card as wide as :width says, and the pieces of footer under it joined by a middot. Every other option is an attribute of the column, which is where a host names the controller that paints what the page stands on.

<%= flow header: logo,
      footer: [sign_out_button],
      data: { controller: 'wall' } do %>
  <%= yield %>
<% end %>

The palettes

Nine of them, served at /bh/theme/<name>.css and linked one at a time after the stylesheet. Each restates all thirteen steps of every Bootstrap family it repaints, plus --bs-white, --bs-black and the three text tones. Every accent clears 3:1 against its label and every text tone 4:1, in both modes.

  • dawn

  • gruvbox

  • nord

bootstrap declares nothing: upstream's palette comes back by dropping the others' block rather than by writing one. It is named anyway, so a toggle can reach it — a reader who rotates through nine and never finds the one the pages started in has been shown a door with no handle on the inside.

Swapping one for another

The scheme controller does it, and the choice belongs to the reader rather than to the app, so it is kept in their browser.

<button type='button' data-controller='scheme' data-action='scheme#rotate'
        data-scheme-themes-value='["bootstrap","nord","dracula"]'
        data-scheme-path-value='/bh/theme' data-scheme-storage-value='scheme'>
  Another palette
</button>

A click moves to another palette and into the mode it is not in. Put the stored choice back before the first paint from the layout's own script: a controller connects far too late for that, and the page would otherwise flash the palette the server chose.

Trying it out

The gem carries a dummy app that draws every helper on one page, and a bin/rails at the root, so there is no cd first. From the root of a clone:

bin/setup
rails s

localhost:3000 is every component at once, ?flash=1 adds the toasts, and /flow is the signup page.
